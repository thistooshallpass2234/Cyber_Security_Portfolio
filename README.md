# Cyber_Security_Portfolio
CTF Experience Reflection:
This is my first CTF experience with Cyber Skyline and it was relatively straight forward when it came to understanding the flow of each of the domains. Unlike other CTF events that I have participated in, this was simplistic in its interface and kept the entire event concise which is something that I rather enjoyed. 

In addition to its simplicity, this event had a specific start and end time without a mandatory break in between. This is something that I observed with NetWars, there is a 3 hour window each day for two days to accomplish as much as possible. This is great if you're geographically located with the host of the event. If you're not, then it can be kind of frustrating to have to do a bunch of hustling during your sleeping hours. 

Throughout the individual competition, I was a little skeptical with using AI when trying to solve many of the challenges. Something that really caught me off guard was the speed in which some of the other competitors were able to solve things. Then it occurred to me that they had incorporated AI agents to help with the accelerated solving of challenges.  Of course I leveraged AI to help with starting points, review some data here and there, and connect a couple of dots that I couldn't quite see yet
